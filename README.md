Student Management System

Project Overview
A Student Management System developed as part of my internship. This application helps manage student information, including enrollment details, personal information, course details, and document uploads.

Features
Add student details
Manage student enrollment information
Store student email and course details
Upload Aadhaar documents
Store and manage student records using MongoDB

Technologies Used
Node.js
Express.js
MongoDB
Mongoose
Multer
HTML, CSS, JavaScript (if applicable)

Project Type
Internship Practice Project

Purpose
Developed during my internship to gain practical experience in backend development, REST APIs, database management, ejs, understanding folder structure and file uploads etc.
